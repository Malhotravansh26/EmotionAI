
# EmotionAI 🧠

AI-powered Emotion Detection using Natural Language Processing and Machine Learning.

## Features
- Text-based emotion detection
- NLP text vectorization using Bag of Words
- Multinomial Naive Bayes classification
- Emotion prediction probabilities
- Interactive Streamlit web application

## Tech Stack
- Python
- NLP
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Project Structure
EmotionAI/
- app.py
- model/
  - emotion_model.pkl
  - vectorizer.pkl
  - label_mapping.pkl
- requirements.txt
- README.md

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
